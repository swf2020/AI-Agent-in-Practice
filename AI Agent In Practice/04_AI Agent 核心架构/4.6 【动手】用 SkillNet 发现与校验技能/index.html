    4.6 用 SkillNet 发现与校验技能

    读完 4.5 有状态 Agent 后，可以继续考虑一个问题：当多个任务都要分析 CSV，如何找到一份可复用的操作规程，并在交给 Agent 之前检查它？

    SkillNet 提供可检索的技能目录，以及创建、评价和连接技能的工具。本节使用其官方 Python 包完成候选检索和结构校验。目录结果中的描述、来源和评价可以帮助筛选候选。论文的任务效果评估需要独立测试环境，本节验证的是技能发现与接入前的检查流程。

    Hugging Face Daily Papers · 论文 · SkillNet 官方仓库

    安装和验证

    在仓库根目录开始，使用 Python 3.10+。安装依赖需要联网，下面的校验只读取本地文件，无需模型密钥。

    cd "libs/AI Agent In Practice/04_AI Agent 核心架构/4.6 SkillNet 技能发现与校验"
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt

    python -m skillnet_ai validate skills/csv-profile --strict --json
python -m skillnet_ai validate skills/csv-profile-invalid --strict --json
    样例 预期结果 退出码
    csv-profile data.valid 为 true 0
    csv-profile-invalid data.valid 为 false，报错指出缺少 description 1

    第二条命令退出后可立即用 echo $? 检查退出码。--strict 还会将可移植性告警视为失败。若找不到 skillnet_ai，先确认已激活虚拟环境并安装依赖。

    检索一个真实候选

    python -m skillnet_ai search csv --limit 3 --json

    检索需要访问 SkillNet 公共目录，结果会随服务数据更新。观察每个候选的 skill_name、skill_description 和 skill_url，根据任务挑选一个候选并在 GitHub 查看原始说明。若服务不可达，可以继续用上面的两个本地样例。SDK 默认使用 HTTP 搜索端点，请使用公开关键词。

    结构通过后，仍需审查候选的 SKILL.md、脚本和依赖所需的权限，以及它们访问文件、网络和凭据的方式。书中样例只用于校验，命令不会执行技能中的步骤。若把候选接入 4.5 节的 Agent，先在隔离环境用已知行数和缺失值的 CSV 验证任务结果。

    练习

    给缺少字段的样例补写一条具体的 description，重跑校验。再写出两条任务验收断言，例如空字段计数符合预期、输入文件哈希保持一致。将这些断言与结构校验分别记录。

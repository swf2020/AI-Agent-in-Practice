# 首次运行

需要 Python 3.10+。在仓库根目录执行以下命令，用第 1.4 节现有的模型注册表做一次本地检查。

```bash
cd "libs/AI Agent In Practice/01_大模型基础与 API 实战/1.4 _动手_统一封装多模型调用层"
python3 -c 'from core_config import get_litellm_id; print(get_litellm_id("GPT-4o"))'
```

预期输出为 `openai/gpt-4o`。这一步只读取本地配置，无需安装第三方依赖或配置模型密钥。若报 `ModuleNotFoundError: core_config`，确认当前目录包含 `core_config.py`。

继续做 [第 1.4 节实验](../01_%E5%A4%A7%E6%A8%A1%E5%9E%8B%E5%9F%BA%E7%A1%80%E4%B8%8E%20API%20%E5%AE%9E%E6%88%98/1.4%20%E3%80%90%E5%8A%A8%E6%89%8B%E3%80%91%E7%BB%9F%E4%B8%80%E5%B0%81%E8%A3%85%E5%A4%9A%E6%A8%A1%E5%9E%8B%E8%B0%83%E7%94%A8%E5%B1%82.md) 时，先在实验目录创建虚拟环境并安装该目录的 `requirements.txt`，再按章节为所选供应商设置环境变量。将真实密钥留在本机。
